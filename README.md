#  Hypotenuse of a Right Triangle Calculator
## Description
The **Hypotenuse of a Right Triangle Calculator** is a simple python program that uses the *Pythagorean Theorem* to calculate the hypotenuse of a right triangle. It uses functions such as *math.pow* and *math.sqrt*. **Important**: The user must enter valid numerical values for the variables *side_a* and *side_b*.
## How to Run
In order for this python code to run, click the python file and input the variables needed.

## Input Needed
***Variables such as:***
* *side_a*
* *side_b*
## Sample Output
Enter the side a: 10 
Enter the side b: 20
The hypotenuse is 22.36
